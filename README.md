# GamePrep · 游戏模式

GamePrep 是一个 macOS 菜单栏小工具。右键点击手柄图标即可清理无关应用、切换到系统自带的 ABC 输入法，并将当前输出设备的音量调到 50%。

## 使用

1. **左键点击手柄图标**打开设置。可以勾选正在运行的应用加入白名单，也可以从磁盘添加 `.app`。设置页会预览当前将收到退出请求的应用。核对后，点击「启用右键执行」。
2. **右键点击手柄图标**执行一轮游戏模式。白名单中的游戏、启动器和其他应用继续运行，Finder、系统服务和后台菜单栏工具也会保留。
3. 左键再次打开设置，即可查看上一次执行结果，包含已退出和仍在运行的应用，以及输入法和音量的设置状态。

GamePrep 向普通应用发送正常退出请求。应用可询问是否保存文档，也可以取消退出。当前输出静音时，调到 50% 会同时解除静音。如果输出设备由外部硬件控制音量，详见执行结果。

白名单保存在本机。退出工具可在设置页点击「退出工具」。需要再次打开时，在「应用程序」中打开 GamePrep。

「登录时启动」默认开启。可以在工具设置里关闭，之后登录 macOS 时将按当前登录项设置启动。游戏模式仍在右键点击手柄时执行。

## 游戏监控

在设置的「游戏监控」里，用「显示监控浮层」单独控制浮层。首次使用这个开关时默认关闭，之后重启 GamePrep 会恢复上次的开关状态。开启并勾选至少一项指标后，浮层会立即显示，桌面也能看到。可以选择屏幕的四角位置、字号、透明度和显示器。镜像屏共用一个角标，系统会将它复制到同组屏幕。

GamePrep 只采集已勾选的指标。关闭开关会隐藏浮层并停止采集。游戏 FPS 来自当前前台进程的 Metal 呈现数据，需要 macOS 提供 `metalperftrace`。没有可用的帧率数据时显示 `FPS —`，其他指标暂不可用时也以 `—` 表示。

## 本机构建与安装

需要 macOS 14 或更新版本，以及 Xcode Command Line Tools。构建只使用 Swift 和 macOS 系统框架。

```sh
./scripts/build_app.sh --install
open /Applications/GamePrep.app
```

应用包使用本地临时签名，安装位置是 `/Applications/GamePrep.app`。只需生成应用包时，可省略 `--install`，脚本会打印仓库外的构建路径。升级后可从设置页退出正在运行的实例，再打开安装好的版本。
