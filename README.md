# GamePrep · 游戏模式

GamePrep 是一个 macOS 菜单栏小工具。右键点击手柄图标即可清理无关应用、切换到系统自带的 ABC 输入法、准备外接显示器并打开 CrossOver。

## 使用

1. **左键点击手柄图标**打开设置。可以勾选正在运行的应用加入白名单，也可以从磁盘添加 `.app`。设置页会预览当前将收到退出请求的应用。核对后，点击「启用右键执行」。
2. **右键点击手柄图标**执行一轮游戏模式。白名单中的游戏、启动器和其他应用继续运行，系统服务和后台菜单栏工具也会保留。游戏模式会关闭访达窗口，访达继续运行。
3. 左键再次打开设置，即可查看上一次执行结果，包含清理应用、外屏、声音和打开 CrossOver 的状态。

GamePrep 向普通应用发送正常退出请求。应用可询问是否保存文档，也可以取消退出。首次关闭访达窗口时，macOS 可能要求允许 GamePrep 控制访达。

接有外屏时，游戏模式会尝试把默认媒体输出切到同名的 HDMI 或 DisplayPort 设备，并在本次 macOS 登录会话使用 2560 × 1440 HiDPI 显示档位。只有一台外屏时选该屏，有多台外屏时仅在主显示器是外屏的情况下调整。当前输出设备支持系统音量控制时，游戏模式会尝试调到 50% 并解除静音。无论外屏准备结果如何，只要已安装 CrossOver，游戏模式都会尝试打开它或唤回运行中的实例。

白名单保存在本机。退出工具可在设置页点击「退出工具」。需要再次打开时，在「应用程序」中打开 GamePrep。

「登录时启动」默认开启。可以在工具设置里关闭，之后登录 macOS 时将按当前登录项设置启动。游戏模式仍在右键点击手柄时执行。

## 游戏监控

在设置的「游戏监控」里，用「显示监控浮层」控制浮层。首次使用这个开关时默认关闭，之后重启 GamePrep 会恢复上次的开关状态。开启开关、勾选至少一项指标，并读到前台游戏的 FPS 后，浮层才会显示。FPS 暂不可用时浮层会隐藏，读数恢复后会重新显示。可以选择屏幕的四角位置、字号、透明度和显示器。镜像屏共用一个角标，系统会将它复制到同组屏幕。

游戏 FPS 来自当前前台进程的 Metal 呈现数据，需要 macOS 提供 `metalperftrace`。帧率约每秒更新一次，显示最新采样窗口的平均值。「游戏 FPS」勾选项只控制是否显示 FPS 一行。其他已勾选指标在浮层显示时采集，暂不可用时显示 `—`。

右键点击菜单栏手柄执行游戏模式时，也会打开「显示监控浮层」开关。手动关闭开关会隐藏浮层并停止采集。

## 本机构建与安装

需要 macOS 14 或更新版本，以及 Xcode Command Line Tools。构建只使用 Swift 和 macOS 系统框架。

```sh
./scripts/build_app.sh --install
open /Applications/GamePrep.app
```

应用包使用本地临时签名，安装位置是 `/Applications/GamePrep.app`。只需生成应用包时，可省略 `--install`，脚本会打印仓库外的构建路径。升级后可从设置页退出正在运行的实例，再打开安装好的版本。
